If you are hoping to compile this mod yourself you need to make one essential change to ApocalypterTalk.csproj

You MUST change <GameDir>CHANGETOYOURGAMEDIR</GameDir>



Normally this would look like 

<GameDir>C:\Program Files (x86)\Steam\steamapps\common\Apocalypter</GameDir>

If you have the game installed to another drive you must point it to the correct directory
